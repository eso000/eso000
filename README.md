## Hi, I'm Eduard 👋

I'm a software engineer with a maths background (M.Sc., University of Ulm). At work I do test engineering for safety-critical systems, and there I rely on mature, well-tested tools like Pytest. In my own time I do the opposite: I write things from scratch to understand how they work under the hood.

### Projects

- **[ttyllm](https://github.com/eso000/ttyllm)**: a terminal UI for Ollama and OpenAI-compatible APIs, written against nothing but the Python standard library. I wanted a more fleshed-out CLI tool, then used it as a playground for a termios-based TUI and a socket-based HTTP parser.
- **[reference-ciphers-python](https://github.com/eso000/reference-ciphers-python)**: six classic block ciphers in pure Python, validated against official test vectors and external oracles. I built it to understand how they work internally.
- **[reference-hashes-c](https://github.com/eso000/reference-hashes-c)**: MD5, SHA-1 and SHA-2 in plain C11, the follow-up to the Python cipher project.

### Tools

Python · C/C++ · Bash · Pytest · Jenkins · Docker · Git · Linux
